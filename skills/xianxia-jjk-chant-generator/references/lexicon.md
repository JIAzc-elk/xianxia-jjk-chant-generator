# 词库与来源边界

本表区分可查原义与创作方向。没有具体出处的复合词不要冠以“出自某经某篇”。表中的“创作方向”均为小说转译。

| 维度 | 候选 | 创作方向 | 使用边界 |
| --- | --- | --- | --- |
| 佛道与时空 | 无住、离相 | 脱离固定方向、解除既定形态 | 佛教概念的文学借用，不是惯性定律 |
| 佛道与时空 | 三际、刹那、须弥 | 时序分割、瞬时触发、尺度折叠 | 仅在神通本身涉及时间或尺度时深入使用 |
| 古籍博物 | 尺木 | 升空凭依、雷翼骨架 | 《论衡·龙虚》引述并质疑相关传说；“以雷为翼”是创作 |
| 古籍博物 | 琥珀 | 吸引、牵引、微物受感 | 古籍常见的是“拾芥／引芥”，不能把古义写成静电排斥 |
| 神话与传统意象 | 金翅、蝉蜕、倒景 | 羽翼、脱壳、越常之境 | 具体典源不确定时只标传统意象，不补造书名 |
| 经史卦象 | 丽天 | 附着高空、锚定天穹 | 《周易·离》彖传，附丽之义；不是本来就指飞行 |
| 经史卦象 | 惊蛰、九野、玄枵 | 唤醒、方位、天区 | 能力关联必须由设定解释，不能只有古雅字面 |
| 古雅律令 | 敕、步虚、垂天 | 下令、步空、展开广域形态 | 不默认杜撰道经原文 |
| 光学 | 全反射、偏光、折射、焦距 | 界面回折、方向筛选、路径偏转、收束 | 全反射有介质与入射条件；用于术法防御时明确是玄幻扩展 |
| 物理与数学 | 位相、共振、临界、坍缩、奇点 | 相位同步、同源放大、阈值、收缩、集中 | 不把词面解释当作完整科学机制；奇点不等于随意创造黑洞 |
| 科学语感造词 | 逆磁、反发 | 逆向磁序、反向放出 | 仅作原创术语，不能宣称是标准学科概念 |
| 原创重构 | 悬衡、盲飙、动静之隙 | 悬置平衡、无向之风、转态间隙 | 无可靠书证时标原创或意象重构 |
| 原创重构 | 折断的白驹、凝滞之川、倒悬之海 | 断续极速、冻结流动、上下颠倒 | 解释违常动作怎样对应实际能力，不写万能效果 |

## 三个常用典故的核验入口

以下链接指向原文转录。版本、断句或异文有争议时，应注明所用文本；不用链接代替原义判断。

- **无住**：[《金刚般若波罗蜜经》鸠摩罗什译本](https://zh.wikisource.org/zh-hant/金剛般若波羅蜜經（鳩摩羅什）)。取无所住之意；“动量清零”是本技能的小说改写。
- **尺木**：[《论衡·龙虚》](https://ctext.org/lunheng/long-xu/zhs)。其中引述“龙无尺木，无以升天”这一说法，作者随后展开质疑。不能写成王充证实龙借雷电升天，也不能把“尺木”直接训成雷电双翼。
- **丽天**：[《周易·离》](https://zh.wikisource.org/wiki/周易/離)。日月附丽于天的原意可借为制空锚定；“接管制空权”是创作解释。
- **白驹**：[《庄子·知北游》](https://zh.wikisource.org/wiki/莊子/知北遊)。原文使用白驹过隙的譬喻，强调人生短暂；“折断的白驹”是原创重构，不是原文。

## 典故与科学的写法

有浏览工具且需要精确出处时，优先查原典；无浏览能力时只引用有把握的短句，其他条目标“出处待核”或改为原创。无需为每个普通词强行寻找古籍。

“雷公墨”可作雷与石的传统想象，但不直接写成“雷击生成的陨石”。“六铢”可作仙衣轻薄的传统意象，未核验具体来源时不要配造书名和引文。

解释一个词至少说清“来路”和“这次借来做什么”。若原典不支持某项效果，把效果放在“神通转译”里，而不是篡改原典。

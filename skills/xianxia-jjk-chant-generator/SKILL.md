# 修仙神通咒词·关键词工坊

把作者的神通描述变成一份可挑选、可组合的关键词库。默认生成 **24 个**候选，作者可指定 **20～30 个**或其他数量。每个词都是有功能的法则触发点，而非单纯好听的技能名。

“咒术风”指冷静、抽象、异质意象并置和参差节奏。创作原创咒词，不复刻《咒术回战》的既有咏唱或术式。优先遵从作者本轮的数量、语气、世界观与输出要求。

## 先判断作者当前要什么

- **给出神通描述、要求关键词、选词或零件库**：进入默认的关键词模式，完整给出20～30个候选；未指定数量时给24个。不要用3～4组成套咒词替代关键词库。
- **已选好词、要求组装**：保留作者选中的词，解释顺序、节拍与分段触发；需要替换时先说明原因并给备选，不擅自推翻定稿。
- **明确要求完整方案或正文示范**：在关键词基础上按需补充3～4组咒词或150～250字实战片段。不要每次都自动追加，淹没供作者选择的候选词。

## 输入处理

从描述中提取：属性、主要作用、使用场景、具体效果、持续时间或代价、语感偏好、禁用词。作者已说清的内容不重复询问；信息不足时，用一句话说明创作假设后继续。只有能力边界的歧义会显著改变结果时，才问一个简短问题。

将视觉特效转译成3～6个底层动作。默认用一句话简述拆解结果，只展示可供作者判断的机制摘要与选词理由。

| 表层效果 | 可用于创作的机制方向 |
| --- | --- |
| 空中锐角转弯、几乎无视惯性 | 解除方向驻留、卸除旧动量、重定轨迹 |
| 周身雷网阻挡远程攻击 | 界面筛选、偏折来袭、隔绝穿透 |
| 雷电双翼、高速飞行 | 升空凭依、锚定高空、压缩行程 |
| 一段时间内雷法增强 | 同源共振、引动本源、提高输出 |

这些是玄幻设定的机制表达。尊重原有持续时间、强弱和代价；“挡远程术法”不能自动扩写成无条件免疫一切攻击，“短时极速”不能自动升级成永久停止时间。

## 五维选词法

先为机制挑词，再让意象彼此照应。按需查阅 [词库与来源边界](references/lexicon.md)，学习完整条目写法时读 [雷翼24词示例](references/thunder-wings.md)。例词供理解方法，每次根据新神通重新创作，不把同一组词换属性复用。

1. **佛道哲思与时空观**：用于破常理、定状态、断因果。例：无住、三际、离相、须弥、刹那、动静之隙。
2. **古籍博物与神话凭依**：用于显化、升空、召唤和引本源。例：尺木、金翅、倒景、蝉蜕。典故原义与小说改写分开。
3. **经史卦象与古雅律令**：用于天地坐标、秩序与敕令。例：丽天、惊蛰、步虚、九野、玄枵、垂天。
4. **半文半理的科学与几何词**：保留冷硬字面与明确机制。例：全反射、偏光、位相、共振、临界、折射、坍缩、焦距。少用教科书口吻和“量子力学、加速度”等过于直白的长术语。
5. **古典意象的暴力重构**：用违常动作折断熟悉意象。结构可为“异态动词＋之／的／与＋时间、空间、自然意象”。例：折断的白驹、凝滞之川、倒悬之海。自然顺口优先，勿批量套同一个句式。

跨维混搭是手段，不是每条都塞满五类。作者指定纯古典时，可完全不用现代术语。不要把“紫电狂闪、烈火焚天”等特效口号当作主体，也不要用“天道、无极、寂灭”的堆叠代替机制。

## 默认输出：关键词模式

开头一句说明底层动作，然后按机制分组，给出**连续编号1～24**的候选；作者指定数量时按其要求。分组标题标注主要作用，帮助作者从不同能力中挑选。一个条目可覆盖多个作用，但每个核心效果都要有若干独立备选。

每条使用以下结构，通常2～4句，让作者不必另查资料就能判断是否选用：

> **序号. 关键词**（对应效果；可选字数）
>
> **来路**：注明“典故借用”“传统意象”“现代术语”或“原创重构”。有可靠篇名时写篇名和必要的短引文；不确定时写“出处待核”或改用自造词。
>
> **神通转译**：具体解释这个词怎样触发该能力，可以连接两三个效果；清楚区分原典含义与本次小说设定。避免“象征强大、代表神秘”这类空泛说明。

分组只是选择辅助，不要求作者每组必选一个。24词应有语义与字面差异，不能把同一个词换“玄、天、寂”前缀凑数。通常兼有2～3字短词与4～6字收束词，也允许少量更长意象；实际字数必须与标注一致。创作型复合词和术语也要能朗读。

**条目示意**：

**无住**（无视惯性）  
**来路**：典故借用，取《金刚经》的无所住之意。  
**神通转译**：在本神通中借作“不驻留于既定方向”：上一瞬的冲势解除，下一瞬重新指定去向。这是小说改写，佛经原义不涉及动量。

**折断的白驹**（极速＋急转）  
**来路**：原创重构，将白驹过隙的时间意象折成一条锐角。  
**神通转译**：将一次高速穿越拆成几段不连续方向，身形在折点换向。若作者已设定随身雷幕，可让雷幕随折线闭合；不凭此词额外赋予时间停止或绝对防御。

末尾可给一条**选词提示**，如“若想突出锐角变向，优先看1、3、5；若想突出雷威，优先看19、21、24”。用索引帮助选择，不替作者直接定稿。不强制追加成套方案、重复表格和正文。

## 作者选词后的组装

按施术逻辑排列：起手定式 → 显化凭依 → 法则干涉 → 收束爆发。必要时说明某词适合起手还是收尾；多个词机制重复时提醒作者取舍。

- 渐进蓄力：2－2－2－3－4－5，或2－2－3－4。
- 短促瞬发：2－2－5，或2－3－3。
- 奇门顿挫：3－2－4－2。

节拍是参考，不能为了凑字破坏作者选中的词。给出真实字数与不同词序的语感差异，避免工整押韵和顺口溜。用户只要选词时，不启动本节。

## 需要实战示范时

写150～250字，咒词随动作与效果分段触发。角色以低声、轻吐或平静断句念出，不默认大吼整段咏唱；允许作者指定其他表演。正文里表现机制，不插入逐词讲解，也不额外发明招式代价或剧情结局。

## 交付前检查

- 数量达到作者要求；默认24个独立候选，每条解释到具体能力。
- 所有核心效果都有备选；同义堆砌、万能套话与批量同构句已删。
- 古籍引文不杜撰，原义、借用与自造明确分开；没有把现代术语伪装成古籍原文。
- 佛理不被宣称为物理学依据；光学概念不被宣称能在现实中反弹任意物体或术法。
- 保留作者的能力边界和选择权，默认停在可选择的关键词库。
